# Session 1b report (2026-09-29): primal-instinct pivot, 3 adrenaline demos

The owner asked for high-octane, primal-instinct games, a target audience chosen with Meta's Horizon direction in mind, and 3 more demos. The owner picked Wolf Night, Hawk Shadow and Shark Wake.

## What's done
- **Audience and genre brief:** `docs/research/2026-09-29-audience-genres.md`, with sources. `STRATEGY.md` has the new thesis section, and `BACKLOG.md` has the pivot block and new seeds.
  - **Audience:** 18–34 mobile short-video scrollers (Reels, Facebook feed, Reddit). They lean male but are near parity on Meta, so the peril is stylised and all-ages.
  - **Genres:**
    1. predators closing in
    2. chase with a visible pursuer
    3. freeze-or-flee
    4. grow-or-be-eaten
    5. a daily "survive the hunt" run for Devvit.
- **Template and engine upgrades** (every game benefits):
  - `Thumb` now carries x/y.
  - Bots may return a position.
  - `endTitleKey` gives "Caught…" / "Made it…" end titles.
  - `engine/fx`: vignette, shake, flash, and a deterministic `TimeWarp`.
  - `Heartbeat` is driven by simulated time.
  - Delayed blips.
- **Shared e2e suite:** `tools/e2e/score-attack.ts`. Each game adds one test for its own input verb; Tidewall was ported to it.
- **Demos:**

  | Game | Verb | Hook | Bundle |
  |---|---|---|---|
  | `wolfnight` | tap toward glowing eyes | Wolves creep in on a lantern. Flash them back; fireflies refuel the oil; survive to dawn. | 12.9 KB gz |
  | `hawkshadow` | hold to run, release to freeze | A hawk's shadow dives on a field mouse, with feints. Freeze at the last instant for close calls. | 12.8 KB gz |
  | `sharkwake` | tap left/right | A fin closes in behind a surfer. Dodge rocks and logs late for near misses; ride wave pads. | 12.9 KB gz |

  Each game has a seeded pure sim, an autoplay bot, strings.json, game.config.json, SPEC.md, HORIZON_PACK.md and RELEASE.md.

## Verified vs mocked
- **Verified (automated):**
  - `npm run check`: 89 unit tests, the size budget for 4 games, typecheck, lint and format.
    - Per game: same seed gives the same event log; different seeds give different layouts; the catch, close-call and near-miss rules; idle play loses fast; bot balance stats.
  - `npm run e2e`: 16 tests (4 games × 4).
    - 0 console errors and no external requests.
    - First input in under 3 s.
    - The round ends and the score is submitted.
    - Share and challenge payloads; restart; the challenge seed round trip.
    - Text ≥16 px at 390×844 and 320×568.
    - Each game's human input path: a wolf tap pushes a wolf back, a hold runs and a release freezes, taps switch lanes.
- **Bot balance on 12–17 seeds:**
  - Wolf Night reaches dawn on about 45% of runs; the others last 34–55 s.
  - Hawk Shadow gets home on 75%.
  - Shark Wake reaches shore on 94%, with 20–30 near misses per run.
  - These numbers make good clips, but they are not human difficulty.
- **Clips:** `npm run clip -- <slug>` produced a 1080×1920 MP4 plus 3 screenshots per game in `out/`, which is gitignored. A side-by-side still is in `out/shots/primal-demos-3up.png`.
- **Mocked / not verified:**
  - Channel SDKs: web and mock adapters only.
  - Audio on a real phone.
  - 60 fps on mid-range hardware.
  - Human difficulty: needs a playtest.

## How to run
```bash
npm ci
npm run dev -w games/wolfnight      # or hawkshadow / sharkwake / tidewall
# /?autoplay=1&speed=2 to watch the bot · /?c=<seed>&s=<score> for a challenge
npm run clip -- sharkwake           # record a 9:16 clip + 3 shots into out/
```
